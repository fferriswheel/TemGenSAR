# 术语与实验名称对照

实验主文使用描述性名称。以下对照用于阅读源代码、结果 CSV 和历史阶段记录；代号本身不代表不同数据上的性能等级。

## 编码、更新与评估

| 术语 | 含义 |
| --- | --- |
| item / 目标 item | 要搜索或推荐的对象，例如商品或电影；目标 item 是一次请求的正确答案 |
| SID（Semantic ID） | 用于生成式检索的离散 item 编码，由多个 token 组成 |
| token | 编码中的一个离散符号；模型逐个生成这些符号 |
| prefix / 共享前缀 | SID 前半部分，两个任务共用；当前为两个 token |
| suffix / 任务后缀 | SID 后半部分，搜索和推荐分别使用；当前各两个 token，单 token 版本是研究计划 |
| codebook / 码本 | 一组向量中心；量化器把连续表示匹配到中心，从而产生离散 token |
| adapter | 表示模型中的小型可训练模块；本项目的 SID adapter 与下游 T5 的 LoRA 不是同一模块 |
| 换码 / recode | item 的实际部署 SID 发生变化；被检测器选中不一定最终换码 |
| collision / 碰撞 | 两个不同 item 拥有相同的完整 SID，导致单靠编码不能唯一识别 |
| churn / 编码变动量 | 一个窗口中有多少 item 或多少编码位置发生变化；口径需看具体统计 |
| replay / 稳定样本回放 | 更新时重用少量旧数据或低漂移 item，帮助保持原有能力 |
| 对齐训练 | 教生成模型关联 item 与编码；例如根据 item 信息预测 SID，或根据 SID 还原 item 信息 |
| token 对齐 | 将刷新码本的新 token 对应到旧 token，降低编号置换造成的扰动；与对齐训练不同 |
| teacher / 蒸馏 | 用旧模型作为教师，约束更新后模型保留稳定样本上的预测能力 |
| LoRA | 冻结基础模型、训练低秩附加参数的适配方式；推荐专用 LoRA 指仅在推荐请求中启用 |
| t0 / 初始模型 | 时序更新之前训练好的表示、SID 与生成模型 |
| W1、W2、… | 按时间排列的数据窗口；例如 W1 更新、W2 测试表示用当前窗口适配，在下一窗口评估 |
| seed / 随机种子 | 控制训练等随机过程的设置；多个增量 seed 共用一个 t0，不等于完整独立训练多次 |
| H@10 | 正确目标进入前十的比例；越高越好 |
| nDCG@10 | 同时衡量命中与排序位置，正确目标越靠前得分越高；越高越好 |
| negatives / 负候选 | 与正确 item 一起参与候选排序的非目标 item；99 negatives 表示一个正例加 99 个负候选 |
| beam size | 每一步生成保留的候选序列数；本仓库主要实验为 10 |
| bootstrap / 置信区间 | 重采样估计结果不确定性；增益区间包含 0 时，不能仅凭均值更高宣称显著改善 |

## 历史方法名称

| 原记录名称 | 本文使用的含义 |
| --- | --- |
| GenSAR-faithful | 在本项目数据与协议中复现的 GenSAR 基线；不是直接引用原论文结果 |
| P1 / v13b | 多视图共享前缀 + 任务专属后缀的主干静态方案；历史两个命名在当前记录中指这一系列 |
| P2 consensus | 尝试更强调多视图共同信息的共识前缀变体；用于检查前缀是否压缩掉任务信息 |
| P1-R | 在主干上显式加入条件残差及完整表示的重构误差约束 |
| P1-RN | 在 P1-R 基础上加入推荐序列邻域信息，增强推荐表示 |
| Fixed / Frozen | 保持 SID 不变；在时序对照中仍继续训练下游生成模型 |
| Random / matched-Random | 按匹配的选择预算随机更新 item；不必然严格匹配支持量或实际换码数 |
| Selective / drift-selected | 根据漂移选 item，并限制只在指定范围内发布新 SID；具体训练方案随实验不同 |
| SupportTopK | 按当前交互量选择前 K 个 item，不使用漂移分数 |
| V3-K51 | 以“漂移分数 × 当前交互数平方根”排序，选择 51 个 item 的推荐更新策略 |
| K150 | 选取 150 个候选 item 的预算，不是独立模型名称 |
| TASR-A | 冻结推荐码本与解码器，仅更新推荐 adapter 的局部更新方案 |
| TASR-B | 允许推荐码本/解码器更新，执行新旧 token 对齐，再选择性发布编码的方案 |
| CG / CG-Sinkhorn | 对碰撞组执行分配调整的后处理；matched CG 指对比两组使用同类处理，最终碰撞率不必相等 |
| Sticky assignment | 在编码分配中加入保持旧码的偏好，减少收益不足的切换 |
| Hungarian alignment | 利用线性分配算法建立新旧 token 对应；本身不保证下游排序改善 |

**特别注意命名重叠：**“P1 方案”是历史模型版本名；SID 里的 P1、P2 是前缀的第一、第二个 token 位置。这两个 P1 含义不同。

R1b、R1d、R1S 等是历史实验编号：分别对应早期推荐选择策略、其三 seed/局部训练验证、以及受控搜索漂移实验。它们用于定位记录，实验解释优先阅读[核心实验](experiments.md)。
