# 背景与相关工作

## 生成式检索与联合搜推

生成式检索将 item 编码为离散 token 序列，由自回归模型根据 query、用户历史或任务提示生成目标 SID。SID 同时承担 item 标识、语义组织和生成模型预测空间三种作用。搜索强调 query–item relevance，推荐依赖行为与协同关系；联合建模需要兼顾共享信息和任务差异。

[GenSAR](https://doi.org/10.1145/3705328.3748071)（RecSys 2025）通过共享与任务相关的编码组织、多任务生成训练统一搜索与推荐，其[官方实现](https://github.com/TengShi-RUC/GenSAR)是本项目下游模型的基础。[Semantic IDs for Joint Generative Search and Recommendation](https://arxiv.org/abs/2508.10478) 研究跨任务表示与统一 SID 空间。这些工作支持联合离散表示的价值，也使“共享哪些语义、保留哪些任务差异”成为 SID 设计的重要问题。

## 时间变化与 SID 兼容性

行为感知 SID 依赖产生它的交互分布。当兴趣、item 共现或 query–item 关系变化时，旧编码可能无法反映当前任务关系。重新训练 tokenizer 可以改善当前表示，却也可能改变大量 item 的编码。下游模型需要学习新目标、处理历史输入变化，并控制共享 token 参数对稳定 item 的连带影响。

相关方法已直接研究这一问题，不能将“动态更新 SID”本身作为充分的新颖性依据。

| 方向 | 代表工作 | 与本项目的关系 |
| --- | --- | --- |
| 持续生成式检索 | [CLEVER](https://arxiv.org/abs/2308.14968) | 增量编码与记忆增强学习，为动态语料上的持续检索提供基础 |
| 漂移感知的持续 tokenization | [DACT](https://arxiv.org/abs/2603.29705) | 使用 item 漂移置信度区分更新，并限制不必要的编码变化；是选择性更新的重要比较对象 |
| 协同 SID 陈旧与 refresh/alignment | [Mitigating Collaborative Semantic ID Staleness in Generative Retrieval](https://arxiv.org/abs/2604.13273) | 将刷新后的 SID 对齐到旧词表以支持 warm-start；与 TASR-B 的 refresh-align 路径直接相关 |
| 面向下游目标的 SID 学习 | [DIGER](https://arxiv.org/abs/2601.19711) | 将推荐目标纳入可微 SID 优化，研究表示重构与下游排序之间的目标差异 |

以上文献用于方法定位；当前实验尚未完成这些方法在统一时序协议下的系统比较。DACT 此处按预印本引用。

## TemGenSAR 的问题定位

本项目研究 **联合搜索与推荐中的任务局部 SID 演化及下游兼容性**，围绕三个问题展开：

1. **结构隔离。** 共享前缀组织跨任务 anchor，Search / Rec 后缀容纳任务信息。当一个任务漂移时，能否保留共享前缀、另一任务的 SID 和未选 item 的部署编码？
2. **更新决策。** 在有限预算下，哪些 item 值得更新？漂移幅度、当前支持量、实际换码范围与下一窗口受影响样本覆盖率之间是什么关系？
3. **下游兼容性。** 新 SID 是否能被生成模型学会？局部目标改善能否转化为总体收益，同时控制稳定样本和另一任务的退化？

当前实现采用多视图共享前缀、任务后缀、漂移选择、稳定 replay、受约束 SID 发布，以及下游对齐与蒸馏。现有结果表明：局部换码可以带来明显的子集排序改善，但自然漂移下整体收益较小，重复换码和下游干扰仍是关键瓶颈。[方法](method.md)与[实验](experiments.md)分别说明实现和证据。

后续研究聚焦于：将预期下游收益与迁移成本纳入 SID 发布决策，以及在旧、新编码视图之间进行兼容性对齐。这些属于[待验证方向](roadmap.md)，尚不构成已完成的方法贡献，也不主张优先性。
