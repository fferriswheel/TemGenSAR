# 最近实验结果对齐（2026-08-12）

## 1. 先统一容易混淆的口径

最近结果中有三种变化不能混在一起比较：

1. **数据规模**：20K item 子集与约 62.8K item 全量集。
2. **SID representation 行为范围**：
   - `train-only`：UniSAR/SID 只使用 temporal-train 行为；
   - `all-behavior`：UniSAR/SID 使用同一数据集全部时段行为。
3. **评估候选集**：
   - 严格协议：1 positive + 999 negatives，`beam=10`；
   - GenSAR 论文推荐协议：1 positive + 99 random negatives，`beam=30`。

此外必须区分：

- **validation**：训练每个 epoch 后在 Rec 1,000 + Search 1,000 条上评估，用于选择 checkpoint；
- **test**：训练结束、加载 best checkpoint 后的最终结果。

昨晚全量实验的 test 配置仍是每个任务抽取 1,000 条；20K 实验的 `test_data_sample_num=0,0` 表示每个任务测试全部 5,000 条。因此二者的绝对值不应直接比较。

## 2. 所有核心实验共享的下游配置

除非单独说明，以下实验均采用：

```text
backbone             = T5-small
training tasks       = SeqRecWithSrcHis, PerSrcWithRecHis,
                       QGenWithRecHis, AdHocSrc_Doc2Query,
                       Item2Index, Index2Item
task sample numbers  = 0, 100000, 1000, 1000, 1000, 1000
epochs               = 3
learning rate        = 1e-3
scheduler            = cosine
batch size           = 32
gradient accumulation= 4
SID codebooks        = [256,256 | 256,256]
seed                 = 2024
strict evaluation    = 999 negatives, beam=10
checkpoint metric    = mean Rec/Search validation nDCG@5
```

比较的两种 SID：

- **GenSAR-faithful**：BGE semantic embedding + UniSAR-faithful collaborative embedding，使用 GenSAR shared/specific RQ-VAE。
- **v13b + CG-Sinkhorn**：M7b-v13b multi-view shared prefix + Search/Rec private suffix，随后使用相同配置的 collision-group Sinkhorn。

v13b：

| 阶段 | Search collided-item | Rec collided-item | Search duplicate | Rec duplicate |

## 6. GenSAR 论文口径校准实验

只对 20K train-only 的同一 best checkpoint 重新评估，不重新训练：

```text
paper-like Rec candidate protocol = 99 random negatives
beam                              = 30
test size                         = Rec 5,000 + Search 5,000
```

| SID | Rec HR@10 | Rec nDCG@10 | Search HR@10 | Search nDCG@10 |
|---|---:|---:|---:|---:|
| GenSAR-faithful | 0.1862 | 0.1020 | 0.2370 | 0.1175 |
| **v13b + CG-Sinkhorn** | **0.3566** | **0.2422** | **0.5538** | **0.3682** |

该实验说明：

- 从 999 negatives 改为 99 negatives 会大幅提高绝对指标；
- `beam=10 -> 30` 的影响远小于候选集从 1000 缩小到 100；
- 论文 Table 3 的高数值首先来自 100-candidate sampled ranking 口径；
- Search 仍未使用论文的 BM25 hard-negative 口径，因此 Search 数值不能直接对照论文 Table 4。

## 7. 当前最稳妥的结论

1. 在目前所有严格同配置比较中，v13b + CG-Sinkhorn 的最终 test 均优于 GenSAR-faithful。
2. 20K all-behavior 能改善 v13b，但没有改善 GenSAR，说明 representation 信息量与 SID 可学习性不是同一问题。
3. 全量数据上两者只训练 3 epochs；GenSAR validation 仍持续上升，当前全量 test 不能视为充分收敛后的最终对比。
4. 全量结果只测试每任务 1,000 条，20K 结果测试每任务 5,000 条；不应据此得出“数据越大效果越差”。
5. train-only 是 temporal drift 主实验应采用的严格口径；all-behavior 更适合作为接近 transductive benchmark 的诊断与对照。
6. 当前最值得继续投入的正式实验是：在同一 representation 口径下延长 GenSAR 和 v13b 的下游训练，并统一使用更大的固定 test 集。

## 9. 六组实验的训练饱和度判断

判断依据是每个 epoch 的 validation mean nDCG@5，即 Rec nDCG@5 与 Search nDCG@5 的平均值。由于当前 cosine scheduler 按 3 epochs 规划，epoch 3 时学习率已经接近 0；这里的“饱和”仅表示在当前三轮 schedule 下进入平台，不能证明模型容量已经充分收敛。

| 数据与方法 | Epoch 1 | Epoch 2 | Epoch 3 | Best epoch | 判断 |
|---|---:|---:|---:|---:|---|
| Full all-behavior / GenSAR | 0.04347 | 0.04594 | **0.04877** | 3 | 未饱和，后两轮仍分别提升约 5.7% 和 6.2% |
| Full all-behavior / v13b | 0.04322 | 0.04478 | **0.04589** | 3 | 提升放缓但未确认饱和；Rec/Search 波动不同步 |
| 20K train-only / GenSAR | 0.02346 | **0.02716** | 0.02699 | 2 | 已进入平台，epoch 3 略回落 |
| 20K train-only / v13b | 0.04952 | 0.07986 | **0.08018** | 3 | 基本平台；epoch 2 到 3 仅提升约 0.4% |
| 20K all-behavior / GenSAR | 0.02923 | 0.02912 | **0.02965** | 3 | 从 epoch 1 起基本平台，三轮波动很小 |
| 20K all-behavior / v13b | 0.04690 | 0.07741 | **0.08307** | 3 | 综合指标未饱和，但提升来自 Search，Rec 连续回落 |

逐任务观察：

- Full GenSAR：Rec 与 Search 均持续提升，是六组中最明确需要延长训练的实验。
- Full v13b：Rec HR@10 在 epoch 1 最高，Search nDCG@5 在 epoch 2 最高，但 mean nDCG@5 在 epoch 3 最高；更像任务不同步，而不是稳定收敛。
- 20K train-only GenSAR：epoch 2 为综合最佳，epoch 3 的 Rec nDCG@5 回落、Search 小幅提升，继续按当前 schedule 训练的收益有限。
- 20K train-only v13b：主要提升发生在 epoch 1 到 2；epoch 2 到 3 基本不变，可视为当前配置下已经平台化。
- 20K all-behavior GenSAR：三个 epoch 的 mean nDCG@5 均约 0.029，属于明显早平台。
- 20K all-behavior v13b：Search HR@10 为 0.063 -> 0.186 -> 0.196，仍在提升；Rec HR@10 为 0.108 -> 0.106 -> 0.102，持续下降。继续训练可能提高综合值，但会扩大任务失衡。

后续训练建议：

1. 优先重跑 Full GenSAR 与 Full v13b 的 6-epoch schedule，从头训练并重新规划 cosine scheduler。
2. 20K train-only 两组可作为已基本稳定的快速比较，不必优先增加训练成本。
3. 20K all-behavior GenSAR 单纯增加 epoch 预计收益有限；v13b 则需要按任务分别监控和保存 checkpoint，不能只依据平均 nDCG@5 判断。

## 10. 严格 paired leave-two-out 实验

本轮修正了旧 20K 实验中 validation/test 用户和时间窗口不严格对应的问题。每个任务分别只保留同时具有 Rec history 与 Search history、且至少有 3 条有效目标记录的用户；按序列顺序使用倒数第二条作为 validation、最后一条作为 test，并从相同用户中各抽取 10,000 人。因此，同一任务内 validation 与 test 是严格配对的相邻未来事件。

```text
items                = 19,999
Rec train/val/test   = 153,981 / 10,000 / 10,000
Search train/val/test= 90,929 / 10,000 / 10,000
training tasks       = 6-task GenSAR protocol
evaluation           = 999 negatives, beam=10
backbone             = T5-small
epochs               = 3
representation       = strict-train only
SID size             = [256, 256 | 256, 256]
```

### 数据与泄漏检查

- Rec 和 Search 各自的 validation/test 用户集合完全相同，且每个集合内用户唯一。
- 每条 validation/test 样本同时具有非空 Rec history 与 Search history。
- SID representation 只使用 downstream strict train 中出现的行为；BGE 文本表征仍只使用静态 item 文本。
- 每条测试样本使用 999 个未交互负样本，ground-truth 不在负样本中。
- 受原始数据按天记录时间戳的限制，Rec 有 26.42%、Search 有 24.06% 的配对样本落在同一天；它们仍按原始序列顺序区分 validation 和 test。

### SID collision

| SID | Search duplicate | Rec duplicate | Search unique | Rec unique |
|---|---:|---:|---:|---:|
| GenSAR-faithful + CG-Sinkhorn | 0.435% | 0.375% | 19,912 | 19,924 |
| v13b raw | 5.305% | 3.620% | 18,938 | 19,275 |
| v13b + matched CG-Sinkhorn | 0.225% | 0.000% | 19,954 | 19,999 |

### Validation 曲线

表中顺序均为 `Rec / Search`。

| SID | Epoch | HR@10 | nDCG@10 | mean nDCG@5 |
|---|---:|---:|---:|---:|
| GenSAR-faithful | 1 | 0.0428 / 0.0600 | 0.02281 / 0.03423 | **0.02353** |
| GenSAR-faithful | 2 | 0.0448 / 0.0555 | 0.02385 / 0.03247 | 0.02338 |
| GenSAR-faithful | 3 | 0.0382 / 0.0559 | 0.01971 / 0.03115 | 0.02098 |
| v13b + CG-Sinkhorn | 1 | 0.0974 / 0.0950 | 0.06304 / 0.06157 | 0.05585 |
| v13b + CG-Sinkhorn | 2 | 0.0964 / 0.1241 | 0.06242 / 0.07814 | 0.06226 |
| v13b + CG-Sinkhorn | 3 | 0.0975 / 0.1430 | 0.06361 / 0.08972 | **0.06847** |

GenSAR-faithful 在 epoch 1 达到综合最优，之后回落；v13b 在 epoch 3 达到综合最优，其中 Rec 已基本稳定，Search 仍在提升。

### 最终 paired test

两组均自动载入各自 validation mean nDCG@5 最优的 checkpoint 后测试。

| SID | Rec HR@10 | Rec nDCG@10 | Search HR@10 | Search nDCG@10 |
|---|---:|---:|---:|---:|
| GenSAR-faithful | 0.0374 | 0.01946 | 0.0534 | 0.02980 |
| **v13b + CG-Sinkhorn** | **0.0791** | **0.05034** | **0.1240** | **0.07740** |

相对 GenSAR-faithful，v13b 的 Rec HR@10 提升 111.5%，Search HR@10 提升 132.2%。在 matched CG-Sinkhorn 后，v13b 的 collision 也没有高于 baseline，因此该差异不能简单归因于 SID 唯一率。

validation 到 test 的 HR@10 相对下降如下：GenSAR Rec 12.6%、Search 11.0%；v13b Rec 18.9%、Search 13.3%。严格配对后仍有合理的未来时间退化，但不再出现旧 full 划分中 validation/test 数量、用户与时间窗口同时不一致的问题。
