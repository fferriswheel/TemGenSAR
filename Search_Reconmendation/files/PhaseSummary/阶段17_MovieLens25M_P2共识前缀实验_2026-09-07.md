# 阶段 17：MovieLens-25M P2 共识前缀实验

日期：2026-09-07

## 1. 实验目的

检验新的 P2 prefix 信息分配方式能否替代 P1/v13b 的全视图融合：

- P1：`common/search/rec` 三个 view 通过 gating 直接形成 t0 shared prefix。
- P2：以 common 为中心，只加入 Search 与 Rec 的一致信息，并限制任务信息对 prefix 的贡献。
- suffix 结构、CG-Sinkhorn、下游任务和训练参数均保持不变。

## 2. P2 结构

P2 的连续 prefix latent 为：

```text
consensus_i = 0.5 * (normalize(search_shared_i) + normalize(rec_shared_i))
z_prefix_i  = LayerNorm(common_shared_i + alpha_i * consensus_i)
0 <= alpha_i <= 0.5
```

训练时加入 Search/Rec task-view dropout、跨任务 agreement、common proximity 和 anchor consistency。prefix 训练完成后冻结，Search/Rec suffix 继续沿用 M7b-v13 的 direct private hierarchical RQ-VAE，再使用相同的 collision-group Sinkhorn。

本次训练中 `alpha` 收敛到上界 `0.5`，等效平均权重约为：

```text
common : search : rec = 0.6667 : 0.1667 : 0.1667
```

这说明当前 gate 没有学出 item-dependent 的融合强度，而是退化为固定的最大 task 注入比例。

## 3. 数据与下游协议

- 数据：MovieLens-25M fixed catalog，18,191 items。
- 表示：同一份 BGE common、UniSAR rec behavior 和 Search embedding。
- SID：`[256, 256 | 256, 256]`，Search/Rec 共用两层 prefix，各有两层 suffix。
- 下游：GenSAR pipeline，T5-small。
- 训练任务：`SeqRecWithSrcHis, PerSrcWithRecHis, QGenWithRecHis, AdHocSrc_Doc2Query, Item2Index, Index2Item`。
- 样本数：`100k, 100k, 1k, 1k, 1k, 1k`，总计 206k。
- 训练：1 epoch，seed 2026，Rec/Search 验证集各 5,000 条，99 negatives，beam size 10。

P1 与 P2 除 SID 文件和输出目录外，下游参数完全相同。

## 4. SID 分布

| 指标 | P1/v13b | P2 consensus |
|---|---:|---:|
| unique shared prefix | 12,144 | 11,008 |
| shared-prefix duplicate fraction | 33.24% | 39.49% |
| prefix quantized effective rank | 8.31 | 22.31 |
| raw Search full-SID duplicate fraction | 0.533% | 0.665% |
| raw Rec full-SID duplicate fraction | 3.705% | 2.732% |
| CG 后 Search duplicate fraction | 0% | 0.022% |
| CG 后 Rec duplicate fraction | 0% | 0% |
| CG 改动 Search item | 1.044% | 1.248% |
| CG 改动 Rec item | 6.784% | 5.035% |

P2 的单层使用率正常，且 Rec raw collision 好于 P1；因此下游退化不能归因于 codebook collapse 或高 collision。

## 5. 下游结果

| SID | Rec H@10 | Rec nDCG@10 | Search H@10 | Search nDCG@10 |
|---|---:|---:|---:|---:|
| P1/v13b + CG-Sinkhorn | **0.6698** | **0.4347** | **0.7104** | **0.4677** |
| P2 consensus + CG-Sinkhorn | 0.5070 | 0.3418 | 0.5236 | 0.3431 |
| P2 相对 P1 | -24.31% | -21.37% | -26.30% | -26.65% |

P2 下游 train loss 为 21.89，P1 为 21.64；P2 的最佳联合 `nDCG@5` 为 0.3101，P1 为 0.4123。

## 6. 结论与诊断

当前 P2 配置被实验否定，不应直接替换 P1。

主要原因不是 collision，而是 prefix 的任务可预测性下降：

1. P2 把 Search/Rec 信息从约各 `1/3` 压到各 `1/6`，Search/Rec reconstruction cosine 也分别从 `0.7727/0.9312` 降至 `0.7320/0.9186`。
2. unique prefix 减少 9.35%，每个 shared prefix 下需要由 suffix 区分的 item 更多。自回归解码首先生成 shared token，这会增加早期 beam 分支歧义。
3. `alpha` 全部饱和到 0.5，预期的“只吸收任务一致成分”没有形成自适应门控。
4. P2 的量化 latent rank 更高，但更高的几何维度没有转化为更强的下游条件可预测性，说明 rank/均衡不能替代任务对齐。

后续不应继续单独调 P2 的 collision。更合理的下一版是在保留 P1 的任务信息量基础上，对 prefix 引入稳定性约束，例如限制 task contribution 的时间敏感方向，而不是整体压低 Search/Rec 权重。
