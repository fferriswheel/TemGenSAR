# 阶段 18：P1 条件残差与 Rec 信息增强对比

日期：2026-09-08

## 1. 实验目的

本阶段回答两个问题：

1. P1/v13b 的 suffix collision 是否主要来自残差重构目标没有被充分优化。
2. 在保持 prefix 为 t0 初始信息、保持 Search/Rec suffix 为领域信息的前提下，仅补充更充分的 Rec 行为信息能否改善 SID 与下游效果。

为此固定 P1 prefix、Search 表征、SID 规模和下游训练协议，只比较以下三组：

| 组别 | 名称 | 相对前一组的唯一主要改动 |
|---|---|---|
| A | P1/v13b | 原始基线 |
| B | P1-R | 在 hierarchical suffix 阶段显式加入条件残差与完整目标 MSE |
| C | P1-RN | 在 B 上将 Rec 表征替换为同源时序邻域增强表征 |

## 2. 固定部分

- 数据：MovieLens-25M fixed catalog，18,191 items。
- prefix：沿用 P1/v13b 的 t0 snapshot-fused prefix，并在 suffix 阶段冻结。
- SID：`[256, 256 | 256, 256]`。
- common：BGE `title + description` 表征。
- Search：相同的 t0 query-item Search embedding。
- 后处理：相同的 collision-group Sinkhorn。
- 下游：GenSAR pipeline，T5-small，seed 2026。
- 训练任务：`SeqRecWithSrcHis, PerSrcWithRecHis, QGenWithRecHis, AdHocSrc_Doc2Query, Item2Index, Index2Item`。
- 任务样本数：`100k, 100k, 1k, 1k, 1k, 1k`，总计 206k。
- 训练与评估：1 epoch，Rec/Search 验证样本各 5,000，99 negatives，beam size 10。

三组下游除 SID 文件与输出目录外参数一致。

## 3. B：P1-R 显式条件残差

### 3.1 审计发现

P1 原实现已经构造了条件残差目标和 prefix-conditioned decoder：

```text
r_search = search_full_target - semantic_base
r_rec    = behavior_target - behavior_base

r_hat_task = D_task([stopgrad(q_shared), q_task])
```

但在 hierarchical direct-Sinkhorn 分支中，`residual_mse`、`residual_cos` 和 `full_mse` 虽被计算和记录，却没有进入最终训练 loss。该分支主要优化归一化后的 full cosine、query contrast、topology、commit 和 balance。

### 3.2 改动

P1-R 在其他项不变时加入：

```text
L_P1-R = L_P1
       + 0.25 * L_residual_mse
       + 0.05 * L_residual_cos
       + 1.00 * L_full_mse
```

实现位于 `stage3/scripts/build_neural_rq_sid_v9_direct_private.py`，新增参数：

- `--hierarchical-residual-mse-weight`
- `--hierarchical-residual-cos-weight`
- `--hierarchical-full-mse-weight`

显式约束使最终 residual MSE 从约 `2.014` 降到 `0.00215`，说明原分支的确没有直接学习该残差目标。

## 4. C：P1-RN 同源 Rec 时序邻域增强

### 4.1 表征构造

C 不引入未来行为，也不引入新的外部字段。它在原 UniSAR item embedding 空间中，使用 t0 temporal-train 交互构造 item 的顺序邻域：

```text
n_i = normalize(sum_j log(1 + count(i,j)) * e_j)
x_rec_enriched = normalize(0.75 * e_i + 0.25 * n_i)
```

- sequence window：2。
- 每个 item 最多保留 200 个邻居。
- 覆盖率：100%。
- 邻域与原 item embedding 平均 cosine：`0.8833`。
- 融合后与原 embedding 平均 cosine：`0.9932`。

因此这是一种保守的同空间增量，而不是重新定义 Rec 语义。实现位于 `stage3/scripts/build_rec_neighbor_enhanced_embedding.py`。

### 4.2 被否决的候选方案

曾尝试从 UniSAR checkpoint 聚合历史上下文 hidden state，但其与静态 item embedding 的平均 cosine 为 `-0.2616`，p10 接近 `-1`，且只覆盖 67.44% items。该表示与当前 item 空间不对齐，未用于 SID 和下游实验。

### 5.2 Rec 区分维度

C 同时提高目标空间与 suffix latent 的有效秩，证明邻域信息增加了 prefix 内的 Rec 区分度，而不只是改变 code usage。

|---|---:|---:|---:|---:|

## 7. 结论

1. **显式残差约束是必要的实现修正，但不是充分的效果改进。** B 显著降低 collision，却未提升总体下游指标，Rec nDCG@10 反而下降约 1.12%。
2. **补充更充分且同空间的 Rec 信息能够改善 suffix 几何和 collision。** C 将 Rec raw duplicate 相对 A 降低约 93.2%，并使 Rec nDCG@10 提升约 0.47%。
3. **仅补充信息还不足以获得稳定的总体提升。** C 的四指标均值与 A 基本持平（`0.5703` vs `0.5706`），Search 略有下降；当前差异也只有单 seed，不应解释为显著胜出。
4. **collision 不是下游效果的充分代理。** C 的 Rec collision 改善了一个数量级，但下游收益很小，后续选模不能继续主要依据 collision。
5. **P1 的“初始信息 prefix + 领域/时变 suffix”分配可以保留。** 本阶段没有证据要求改回纯 common prefix；更需要的是让 suffix 学习对 prefix 有条件增益、且对下游可预测的 task-private 信息。

## 8. 下一步建议

不建议立即只扩大邻域信息或调大融合权重。下一轮应围绕一个更直接的结构目标：

- 保留冻结 P1 prefix 与 C 的同源 Rec 增量作为输入候选。
- 在同一 prefix bucket 内加入 task-aware contrastive discrimination，让 suffix 优先区分 prefix 已无法区分、但下游行为不同的 items。
- 加入轻量 redundancy 约束，减少 suffix 与 prefix 重复，但不强制正交全部语义方向。
- 先做 SID 诊断与 1-seed 下游；只有总体指标明确超过 A 后再运行 3 seeds 和 temporal update。
